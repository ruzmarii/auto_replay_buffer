# Автоматизация буфера повтора OBS Studio

Легковесный Lua-скрипт для OBS Studio, управляющий автозапуском буфера повтора и паузой после сохранения.

Доступно на других языках: [English](README.md)

## Возможности
- **Автозапуск при старте**: включает буфер повтора при открытии OBS Studio.
- **Пауза после сохранения**: останавливает буфер на 30 секунд после сохранения клипа, затем автоматически запускает его снова.
- **Безопасная ручная остановка**: ручное отключение буфера не вызывает автоматический перезапуск.
- **Поддержка языков**: автоматически определяет язык интерфейса OBS (русский и английский).
- **Отключено по умолчанию**: все функции изначально выключены.

## Установка
1. Включите буфер повтора в OBS: **Настройки** → **Вывод** → **Буфер повтора** → отметьте **Включить буфер повтора**.
2. В главном меню OBS откройте **Инструменты** → **Скрипты**.
3. Нажмите кнопку **+** и выберите файл `auto_replay_buffer.lua`.
4. Включите нужные функции в панели настроек скрипта.

## Настройки

| Параметр | По умолчанию | Описание |
| :--- | :---: | :--- |
| **Автозапуск буфера при старте OBS** | Отключено | Запуск буфера при открытии программы |
| **Задержка автозапуска при старте OBS (мс)** | 1500 | Задержка в миллисекундах перед запуском |
| **Останавливать буфер после сохранения повтора** | Отключено | Остановка буфера после сохранения клипа |
| **Время остановки перед перезапуском (мс)** | 30000 | Длительность паузы в миллисекундах до перезапуска |
